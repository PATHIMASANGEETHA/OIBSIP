# 📚 MyLibrarySystem - Java Console Project

This is a simple Library Management System using Java. It allows you to:
- Add books
- View books
- Issue books
- Return books
- Search books

## 💻 How to Run It

1. Open the terminal in your project folder.
2. Compile the program using:

    ```
    javac Books.java MyLibrarySystem.java
    ```

3. Run the program using:

    ```
    java MyLibrarySystem
    ```

## 📁 Files in this project:
- Book.java – Contains the Book class
- MyLibrarySystem.java – Main logic and user menu
- README.md – This file
